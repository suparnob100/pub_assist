How this works: write and compile your LaTeX in whatever editor you prefer (TeXstudio, VS Code + LaTeX Workshop, a MiKTeX/TeX Live setup, etc.). Use Pub Assist for the processing steps below — point each step at your project folder on disk.

Step 1 New LaTeX Project Create a structured LaTeX project folder ready to open in your editor.

Pub Assist creates a clean manuscript folder and manuscript.zip inside this destination. Existing files already in the destination are not zipped.

Overleaf upload Keep Create zip archive checked. Step 1 creates manuscript.zip beside the new manuscript folder; upload that ZIP in Overleaf with New Project > Upload Project. No ZIP generated yet.
Step 2 Reassemble Document Merge modular section files back into a single manuscript .tex file.
Step 3 Clean LaTeX Strip comments and unused code via arxiv_latex_cleaner.

Cleans the file in an isolated temp folder, writes <name>_cleaned.tex next to the original, then removes the temp folder.

Step 4 Beautify LaTeX Apply indentation and comment alignment. Writes a *_beautiful.tex file.
Step 5 Review Floats Extract figure, table, and equation environments into a *_floats_only.tex file.
Step 6 Reviewer Response Template Generate a structured LaTeX response-to-reviewers file.
Step 7 LaTeX Diff Generate a diff.pdf comparing old and new manuscript versions.

Use none unless both old and new projects include the needed .bib files.

Keep this outside both old/new project folders. If the workspace is inside a selected project, the generated zip can become huge or corrupt.

Docker mode uses Docker Hub image am009/latexdiff-web-worker. Pre-download with docker pull am009/latexdiff-web-worker.

Step 8 Collect Figures Copy all referenced figures into a Figures_/ folder and update paths.
Step 9 Submission Documents Generate the full .docx submission packet (cover letters, highlights, conflict of interest, and more).

Paste a JSON config matching the notebook's input variables. Use the notebook as your editor — this form accepts the same keys.

Modularize LaTeX File Split a monolithic .tex file into per-section files under a sections/ folder.
One Sentence per Line Reformat .tex files so each sentence starts on a new line — cleaner Git diffs.
TexCount Generate word-count reports for a LaTeX manuscript using the TeXcount website.

Default mode sends only the selected .tex file content to the TeXcount web service and saves the returned report. Use local mode only when texcount and Perl are working on your system.

DOI → BibTeX Fetch BibTeX entries from DOIs, DOI URLs, journal article URLs, or saved article HTML files.

If a line is a journal article URL, Pub Assist saves that page to a temporary local HTML file, extracts the DOI, then deletes the temporary file. If a publisher blocks automated reads, save the article page from your browser with Ctrl+S or a save-page extension such as Save Page WE, then select the saved HTML file above. Generated BibTeX appears below and is written to the selected file.

BibTeX Cleaner Tidy an existing .bib file using bibtex-tidy with the online BibTeX Tidy style options.
Route 1: Website Bundle

Default. Pub Assist downloads the BibTeX Tidy website's JavaScript bundle, runs the same tidy function, then saves and previews the cleaned BibTeX here. This avoids installing the npm package.

Route 2: Local npm/npx

Use the npm package directly. Keep the default npx --yes bibtex-tidy@latest command, or install globally with npm install -g bibtex-tidy and set the command to bibtex-tidy.

The default cleaner preset matches the shared online UI: braces, numeric values, tab indent, align at column 13, duplicate-key check, no escaping, sorted fields, and duplicate fields kept. Default mode writes a cleaned copy; turn on Modify input file only when you want in-place tidying. The website-bundle engine avoids npm package installation, but it still needs Node.js to execute the website JavaScript.
