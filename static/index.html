How this works: write and compile your LaTeX in whatever editor you prefer (TeXstudio, VS Code + LaTeX Workshop, a MiKTeX/TeX Live setup, etc.). Use Pub Assist for the processing steps below — point each step at your project folder on disk.

Step 1 New LaTeX Project Create a structured LaTeX project folder ready to open in your editor.
Modularize LaTeX File Split a monolithic .tex file into per-section files under a sections/ folder.
One Sentence per Line Reformat .tex files so each sentence starts on a new line — cleaner Git diffs.
Step 2 Reassemble Document Merge modular section files back into a single manuscript .tex file.
Step 3 Clean LaTeX Strip comments and unused code via arxiv_latex_cleaner.

Cleans the file in an isolated temp folder, writes <name>_cleaned.tex next to the original, then removes the temp folder.

Step 4 Review Floats Extract figure, table, and equation environments into a *_floats_only.tex file.
Step 5 Collect Figures Copy all referenced figures into a Figures_/ folder and update paths.
Step 6 Beautify LaTeX Apply indentation and comment alignment. Writes a *_beautiful.tex file.
Step 7 Reviewer Response Template Generate a structured LaTeX response-to-reviewers file.
Step 8 LaTeX Diff Generate a diff.pdf comparing old and new manuscript versions.

Use none unless both old and new projects include the needed .bib files.

Docker mode uses Docker Hub image am009/latexdiff-web-worker. Pre-download with docker pull am009/latexdiff-web-worker.

DOI → BibTeX Fetch BibTeX entries from a list of DOIs via doi.org / Crossref.
Copy Style Files Copy required .sty files from MiKTeX into the project folder.
Step 9 Submission Documents Generate the full .docx submission packet (cover letters, highlights, conflict of interest, and more).

Paste a JSON config matching the notebook's input variables. Use the notebook as your editor — this form accepts the same keys.
